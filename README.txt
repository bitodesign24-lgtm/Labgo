LABGO — prototype web HTML/CSS/JavaScript
Buka index.html di browser atau upload folder LABGO ke Netlify Drop.
Login demo: masukkan email/NIM/NIP dan sembarang kata sandi nonkosong. Tidak ada autentikasi nyata. Jangan gunakan kata sandi asli.
Data booking dan profil disimpan di localStorage browser. Jadwal, peserta, dan persetujuan adalah data simulasi; tidak terhubung dengan database kampus. Lampiran hanya menyimpan nama file. Tidak ada pembatalan otomatis berdasarkan jam. Untuk mencoba check-in/out pilih booking contoh berstatus Disetujui.
Kelas 204 diseragamkan menjadi 60 orang mengikuti daftar pencarian dan jumlah kursi. Aset logo dan foto dipotong dari referensi PNG, bukan aset Figma asli. Font menggunakan Arial sebagai pendekatan. Tanggal kalender awal mengikuti screenshot Oktober 2025.
